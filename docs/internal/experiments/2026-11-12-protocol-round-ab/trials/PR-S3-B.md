## 2. 是否上报用户

**是，强制上报**（达限即上报，不得第 N+1 次重试）。上报内容按「升级报告三要素」组织：

- **当前状态**：T7（修复构建失败）= failed；三次 fail 跨 retry 累计（fail_streak=3）达缺省上限；失败原因序列：①依赖缺失 ②环境变量未注入 ③构建脚本超时（各不相同）；板上无其他在途执行。（若执法开启：T7 已自动转 escalated，待用户 retry。）
- **已尝试方案**：第 1 次失败（依赖缺失）→ retry 重派；第 2 次失败（环境变量未注入）→ retry 重派；第 3 次失败（构建脚本超时）→ 已 fail 记录并按纪律停止重试。
- **建议选项**：a) 换人——改派 DevOps 自动化工程师先修依赖安装与环境变量注入（环境/部署/发布/凭据类操作属其领域），环境基线固定后再回构建修复；b) 拆解——请 PM 把「环境准备」与「构建修复」拆为两个子任务串行重排（写型串行）；c) 范围调整——先只修依赖+环境注入并单独验收，构建超时（如超时阈值）另立小任务；d) 放弃/暂缓 T7。另附：本会话召唤成本估算已超预算（5.2K/3K），继续派工建议按 cost 档路由或简化任务书，或上调阈值/显式豁免。

## 3. 依据纪律原文（逐字引用）

来源：§3「执行编排」—「循环检测与人工升级（方向 3，四轴分工）」条，第④轴：

> ④ **连续失败循环**——同一任务 `fail`→`retry` 再 `fail` 跨重派累计（`fail_streak`），**达 3 次（`DSH_EXPERT_FAILLOOP_LIMIT` 可调）强制升级**：`DSH_EXPERT_FAILLOOP_ENFORCE` 显式开启后第 N 次 `fail` 工具级自动转 **escalated**（唯一出口=用户 `retry`，重置计数再给一轮预算；`done` 成功清零），执法关闭时为协议纪律（编排者自查事件流累计，达限不得第 N+1 次重试、上报用户）

同条·升级报告三要素：

> **升级报告三要素**（上报用户必填）：当前状态（任务板条目+最新检查点）、已尝试方案（每次失败的原因与处置动作）、建议选项（换人/拆解/范围调整/放弃）。

§3「专家失败或结论可疑」条（为何不自行换专家硬试）：

> 专家失败或结论可疑：换专家重试、改用自带库，或进第 4 节请 PM 重排，不要反复硬试同一调用；任务板对应条目 `fail` 记录原因；中断专家的续跑按第 3 节断点续跑两态处置（新一代宿主 summon 通道自动续跑恰好一个 turn；其余按一次性纪律以检查点+全新代理重跑）。

§9 工具速查 fail/retry 行（用户出口的命令形态）：

> python3 <技能目录>/tools/taskboard.py fail T3 "原因" ; retry T3  # retry 亦为 escalated 唯一工具内出口：用户显式解除升级（回 ready 并重置 repair 重试预算）

辅助依据：§0 五锚自检【锚3·反跑题】「连续 2 轮无实质进展→强制换策略或召 PM 重排」——本场景的具体出口由失败循环纪律接管（上报用户，PM 重排作为选项 c 供裁决）。

## 4. 附加题：成本熔断信封解读与下一步动作

**逐字解读**：通道=成本（token 熔断）；「现状」槽位=会话召唤累计估算 5.2K 已超预算 3K，估算口径为**字符启发式、非计量值**；尾行「本提示不阻断。」是协议固定字面 → 本行为**提示级信封**（提示行，不改变任何板面/状态，不构成阻断）。机制来源是 `DSH_EXPERT_TOKEN_BUDGET` 显式开启（缺省关闭）后 summon 结果尾部附加的成本熔断提示。

**依据原文**：§3「升级信封规范」：

> **升级信封规范（四通道统一格式，提示级/执行级）**：所有升级/告警类提示行统一为 `【升级｜<通道>｜<级别>】现状：<机制化状态>。建议：<可行动选项>。`——通道=振荡（策略乒乓）/连续失败（召唤或任务板循环）/预算（调用发散，级别 告警档/收尾档/中断档）/成本（token 熔断）；提示级（提示行，不改变任何状态）尾行恒为「本提示不阻断。」，执行级（工具已完成状态迁移，如 fail-loop 自动 escalated）不带尾行

§3「模型路由三档偏好」·级联降档重试：

> **级联降档重试**：模型不可用或成本熔断（【升级｜成本｜熔断】信封行出现）时，按 quality→balanced→cost 顺序手动换 `model` 重试——插件内不做自动 fallback（既有裁决），降档动作由编排者执行并在板检查点留痕。

§9 运行时门禁开关速查：

> DSH_EXPERT_TOKEN_BUDGET=<千token正数>  # 成本熔断提示开启（编排经济学，缺省关闭）：会话召唤累计估算达阈值时 summon 结果尾部/批量结果尾部附【升级｜成本｜熔断】信封行（字符启发式估算非计量值，提示级不阻断，§3 升级信封规范）
