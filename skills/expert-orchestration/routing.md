# 任务类型 → 专家路由表

> 本文档为活文档，依据任务板 metrics 聚合数据持续迭代。

## 使用说明

- 专家名有两类来源：**合并花名册**（SKILL.md §6：bundled-core + 已启用外部来源，**主供给**，可查 `expert-sources/merged/roster.json`；跨源重名按去重代表规则选人，见 SKILL.md §6）与**自带库**（本技能 `experts/` 目录下真实存在的 `title`）。首选优先合并花名册；花名册无匹配或专家不可用时，按备选回退自带库。**Agency 花名册（dsh-agency-agents）为可选补充**：未安装 dsh-agency-agents 时本路由表完整可用；已安装时其花名册视为额外来源并入候选，不构成依赖——合并花名册优先，Agency 为可选补充。表中自带库为首选的条目，即按「首选优先合并花名册、无匹配回退自带库」预设后的回退结果，非例外。
- 每条一行选择依据，说明"为什么选它"，避免把某一位当默认实施角色（SKILL.md §3）。
- 派发前仍须遵守 SKILL.md §3：共享工作树写互斥、委派任务书模板、写型任务带红线声明。

## 路由表

| 任务类型 | 首选专家 | 备选专家 | 一行选择依据 |
|---|---|---|---|
| 修复 / 收口 / 小改 / 版本收尾 | 低风险变更工程师 | Debugger（自带库） | 最小改动、可回滚偏好是首选的长处；涉及回归与根因排查时用 Debugger |
| 功能实现 - 后端 | 后端工程师 | 后端架构师 | 服务端接口、业务逻辑、数据库与 API 契约是其核心适用任务；涉及服务拆分设计升级为架构师 |
| 功能实现 - 前端 | 前端开发者 | 前端工程师（自带库） | 页面/组件、样式交互与浏览器兼容归前端执行专家 |
| 跨栈架构设计 | 软件架构师 | Microservices Architect（自带库） | 跨栈设计需限界上下文与权衡分析；单体拆分布式服务时切自带库分布式架构师 |
| 环境部署发布 | DevOps 自动化工程师 | 运维工程师（自带库）；Terraform Engineer（自带库，IaC 专项） | 装依赖、装运行时、部署发布与 git push 之外的主机操作归运维；基础设施即代码专项用 Terraform Engineer |
| 技术文档 | 技术文档工程师 | 通用执行专家（自带库） | 文档须与实际行为一致、示例可运行，归专职文档角色 |
| 代码评审 | 代码审查工程师 | 代码审查专家（自带库） | 评审者与实现者必须不同领域（SKILL.md §4 独立评审门禁），按严重程度分级输出 |
| 安全审计 | 安全工程师 | 安全审计专家（自带库） | 漏洞排查、依赖与配置审计、注入/越权/敏感信息检查，只读审计不改代码 |
| 提示词工程 | 提示词工程师 | 多智能体系统架构师 | 提示词与 Agent 行为设计是专职领域；涉及多专家编排协议设计时用多智能体架构师 |
| 数据管道 / 数据库 | 数据工程师 | 数据库性能工程师；Database Administrator（自带库） | 数据管道与建模归数据工程师；数据库性能专项用数据库性能工程师，高可用/容灾/备份用 Database Administrator |
| PostgreSQL 深度调优 | Postgres Pro（自带库） | Database Administrator（自带库） | 查询优化、复制、备份与 PostgreSQL 高级特性专项兜底 |
| 故障应急 / 事故处理 | 故障应急工程师 | SRE（站点可靠性工程师） | 线上事故需按证据链止血与恢复；事后可靠性改进与 SLO 归 SRE |
| 韧性演练 / 故障注入 | Chaos Engineer（自带库） | SRE（站点可靠性工程师） | 受控故障实验须有稳态假设、爆炸半径与自动回滚预案，属专职混沌工程领域 |
| 项目管理规划 | 高级项目经理 | 项目经理（规划）（自带库） | 需求拆解、排期、验收标准与范围风险控制归 PM，只规划不执行 |
| 进度 / 风险 / 检查点跟踪 | 项目推进专员 | 高级项目经理 | 节点推进、风险预警与检查点汇报属推进型角色；计划需重排时升级 PM |
| 测试与验收 | 测试工程师（自带库） | 代码审查工程师 | 用例设计、回归验证、缺陷复现须以实际执行为准 |
| 性能优化 | Performance Engineer（自带库） | 数据库性能工程师 | 瓶颈定位、负载测试与系统调优；数据库专项切数据库性能工程师 |
| LLM / AI 应用 | Llm Architect（自带库） | 提示词工程师 | 生产级 LLM 架构（微调、RAG、推理成本与安全）是专职领域；纯提示词编写用提示词工程师 |
| 重构 / 遗留改造 | Refactoring Specialist（自带库） | 低风险变更工程师 | 行为保持的结构性改造需专项方法；小范围收口改回低风险变更工程师 |

## 维护约定

1. 新增条目时先核实专家名：只允许合并花名册名（含 Agency 花名册名——Agency 为可选补充来源）或 `experts/` 目录 frontmatter 中真实存在的 `title`，禁止编造。
2. 任务板 metrics 显示某类任务反复路由错误时，优先调整该条目的首选/备选，而不是新增专家。
3. 修改本表不视为改 SKILL.md；本表是 SKILL.md §3 路由细则的细化参考，冲突时以 SKILL.md 为准。
